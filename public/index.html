Browser login required

Your projects and cards are private. This browser needs its own login session; MCP access does not sign you in.

From the Kanban Lite repository, run this command in a terminal on the computer running the board: 

node dist/src/cli.js open --data-dir /path/to/your/kanban-data

Replace the path with the data directory shown in the service terminal or configured in your MCP adapter. If using an installed package, replace node dist/src/cli.js open with kanban-lite open.

The command opens your default browser without restarting the board or signing out other browsers. On macOS, add --browser "Google Chrome" to open Chrome.

Login links work once and expire after five minutes. Sessions last eight hours; run the command again when needed.
