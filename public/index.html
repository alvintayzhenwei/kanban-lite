Need help?

If you lost your passkey, use First-time setup to recover access and create another. Login links work once and expire after five minutes; browser sessions last eight hours.

Running from source? Use node dist/src/cli.js open instead of kanban-lite open. On macOS, add --browser "Google Chrome" to open Chrome.

Your credential manager or security key stores the private key. Kanban Lite saves only the public key and credential metadata, never your private key, fingerprint, or PIN.
